Вот идеи на будущее по категориям

---

## 🟢 Простые (1-2 часа каждая)

**Pomodoro режим**
```bash
bun cw pomo start "Deep work" --work=25 --break=5
# таймер отсчитывает, пищит (bell \x07) когда время вышло
# автоматически переключает work/break циклы
```

**Заметки к задаче**
```bash
bun cw note "нужно согласовать с дизайнером"
# добавляет notes: string[] к активной задаче
# видно в логе рядом с задачей
```

**Алиасы задач**
```bash
bun cw alias add standup "Daily standup" --tag=work --est=15
bun cw standup   # = bun cw start "Daily standup" --tag=work --est=15
# хранится в config.json → aliases: {}
```

**Стрики**
```bash
bun cw streak
# streak: 🔥 12 days  (отработал > X часов каждый день)
# считается из history по датам
```

---

## 🟡 Средние (полдня каждая)

**Цели на задачи, не только на день**
```bash
bun cw goal set --tag=study 2h    # минимум 2ч учёбы в день
bun cw goal set --tag=health 1h
# в clock показывает прогресс по каждому тегу отдельно
```

**Недельный обзор (weekly review)**
```bash
bun cw review
# показывает:
# — выполнил ли цели каждый день
# — топ задачи
# — сравнение с прошлой неделей (+12% время на работу)
# — дни когда не работал вообще
```

**Блокировка отвлечений (focus mode)**
```bash
bun cw focus start --dur=90
# записывает в /etc/hosts блокировку сайтов из config
# по окончании — убирает блокировку
# требует sudo один раз при установке
```

**Теги как проекты с бюджетом**
```bash
bun cw project add client-x --budget=40h --deadline=2025-07-01
bun cw project status client-x
# потрачено: 28h / 40h бюджета
# осталось: 12h · дедлайн через 18 дней · темп: ок
```

## 🔴 Сложные (день+)

**TUI dashboard** (весь экран, навигация стрелками)
```
┌─ today ──────────────────┐ ┌─ week ───────────────────┐
│ ▶ Design review  0h 42m  │ │ work    ████████  14h     │
│                          │ │ study   ████      4h      │
│ today  ████░░░  5h/8h    │ │ health  ██        1h      │
└──────────────────────────┘ └──────────────────────────┘
┌─ log ────────────────────────────────────────────────┐
│ · 09:12  Morning emails        #work      1h 20m     │
│ · 10:35  Design review         #work      0h 42m ●   │
└──────────────────────────────────────────────────────┘
  j/k навигация · enter детали · s стоп · n новая задача
```

**Автодетект задач** — смотрит на активное окно/процесс:
```bash
bun cw auto start
# каждые 30 сек смотрит через `xdotool` / `osascript` (mac)
# что за приложение активно → предлагает тег
# "вижу VS Code → #work?  y/n"
# хранит маппинг app → tag в конфиге
```

**Экспорт в Notion**
```bash
bun cw export --notion
# через Notion API создаёт/обновляет Database
# каждая задача = строка с полями: Name, Tag, Date, Duration
```

**Инсайты с AI**
```bash
bun cw insights
# отправляет агрегированную статистику (без названий задач если хочешь приватность)
# в Claude API → получает текстовый анализ:
# "Ты работаешь продуктивнее по вторникам утром.
#  На учёбу уходит на 40% меньше чем планируешь."
```

---



Если расставлять по соотношению усилия/польза:

1. **Pomodoro** — классика, добавляет структуру к таймеру
2. **Стрики** — мотивирует продолжать, данные уже есть в `history`
3. **Цели по тегам** — логичное развитие текущих целей
4. **Алиасы** — убирает рутину для повторяющихся задач
5. **TUI dashboard** — самое крутое визуально, но и самое долгое
